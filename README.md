# Игры через MCP

Подключи свою нейросеть по MCP, и она сделает тебе браузерную игру

Сайт **#1** из челленджа «Сайт через день» блога **Без магИИ**: зрители предлагают идеи, самую
залайканную я делаю с ИИ и выкладываю в прод. В ролике видно, сколько ушло времени и что пришлось чинить руками.

- Сайт: https://project1.bezmagii.site
- Все сайты челленджа: https://bezmagii.site

## Стек

Фронт: React + Vite + SCSS modules. Бэк: Fastify + SQLite (Drizzle). Полоса челленджа, подвал,
тема, статистика и деплой взяты из моей заготовки, общей для всех сайтов челленджа.

## Запуск

```bash
npm install
cp .env.example .env
npm run dev        # фронт http://localhost:5173, API http://127.0.0.1:3000
npm test           # тесты бэка
```
